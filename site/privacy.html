Your data, clearly explained.

This page describes the current development version of Nylo. Contact the project at admin@colorforfun.app with privacy questions. Final store disclosures will be checked against the release build before publication.

On your device

Nylo saves conversations, drafts, agent instructions, memories and connection settings locally. Native API keys are stored separately in the platform’s secure storage. Chat databases are not protected by a separate Nylo password. Device protection, uninstall and OS backup behavior can differ by platform.

When you contact an AI provider

After your permission, Nylo sends conversation context to your selected provider. Agent conversations also include that agent’s instructions and saved memories. The API key authenticates those requests. Model discovery sends the key to the selected provider to retrieve model IDs, without chat history.

Your provider receives network information such as your IP address and applies its own privacy, retention and billing policies. Nylo cannot promise zero provider retention. For OpenAI, requests set the API’s storage option to false; this is not a promise that all provider logs or retention are disabled.

Custom provider endpoints are chosen by you. Confirm that you trust their exact HTTPS destination before entering credentials or sending private information. Do not enter passwords or API keys into chat messages.

No Nylo cloud account or analytics

The current app has no Nylo account, automatic chat synchronization, advertising SDK or analytics SDK. This public support website is hosted on GitHub Pages; its hosting provider may process ordinary website access information under GitHub’s privacy statement.

Backups and deletion

Exported backups contain readable chats, agent instructions and memories, but exclude stored API keys. Keep exports private and delete any copies you no longer need. Restoring replaces local application data and removes saved provider keys. Conversations, agent memories and saved connections can be removed in the app. There is no Nylo cloud account to delete.

Support

If you email support, your email and the information you choose to include are received for handling that request. Avoid sending credentials or entire private conversations. Ask support to delete your correspondence when it is no longer needed; retention obligations and the email provider’s processing may apply.

Changes

If later versions add cloud services, reporting, accounts or analytics, this policy and the store declarations must be updated before those features are released.
