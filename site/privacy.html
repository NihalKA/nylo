Your data, clearly explained.

Nylo is an iPhone app intended for adults aged 18 and older. Contact us at admin@colorforfun.app with privacy questions.

On your device

Nylo saves conversations, drafts, agent instructions, memories and connection settings and selected attachments locally. Nylo supports photos, optional camera capture, PDFs and readable text files. Images are re-encoded before storage without original EXIF metadata; visible image details and PDF/text content may still identify people. Picking a file or photo does not upload it. Camera access is requested only when you choose Take a photo, and can be denied without preventing text chat. Native API keys are stored separately in the platform’s secure storage. Chat databases are not protected by a separate Nylo password. Device protection, uninstall and OS backup behavior can differ by platform.

When you contact an AI provider

After your permission, Nylo sends conversation context to your selected provider. Agent conversations also include that agent’s instructions and saved memories. If you enable recent-chat context for an agent, bounded text excerpts from up to eight recent chats with that same agent can also be included (up to 12,000 characters). Other agents and ordinary chats are excluded. Review or turn off this context in the agent’s Memory section. Files themselves are excluded from cross-chat excerpts; conversation text quoting, describing or discussing those files may be included. The API key authenticates those requests. Model discovery sends the key to the selected provider to retrieve model IDs, without chat history.

Sharing approval is remembered for conversations using the same saved connection and destination. Reset it under Settings → Connect your AI to require permission again before the next message. Changing the key or destination requires new approval. Resetting approval does not erase information already received by a provider.

Your provider receives network information such as your IP address and applies its own privacy, retention and billing policies. Nylo cannot promise zero provider retention. For OpenAI, requests set the API’s storage option to false; this is not a promise that all provider logs or retention are disabled.

Custom provider endpoints are chosen by you. Confirm that you trust their exact HTTPS destination before entering credentials or sending private information. Do not enter passwords or API keys into chat messages.

Each send involving attachments asks permission to send attached content from that conversation to the named provider. The attachment remains part of the conversation and can be sent again with later messages. Model support varies; an available model is not proof of image, PDF or memory-tool support. Provider charges can include file and image processing.

Every durable memory proposed by an agent requires your approval. You can edit or remove saved facts. Removing a memory does not erase mentions from earlier conversations, exports or provider-held copies. Disable recent-chat context or remove source conversations to stop those excerpts from being included in future requests.

No Nylo cloud account or analytics

Nylo has no chat-storage backend. We do not receive your conversations or attachments on a Nylo server. The app has no Nylo account, automatic chat synchronization, advertising SDK or analytics SDK. Your selected AI provider receives requests as described above. This public support website is hosted on GitHub Pages; its hosting provider may process ordinary website access information under GitHub’s privacy statement.

Backups and deletion

Exported backups contain readable chats, selected attachments, drafts, agent instructions and memories, but exclude stored API keys. Keep exports private and delete any copies you no longer need. Restoring replaces local application data and removes saved provider keys. Conversations, agent memories and saved connections can be removed in the app. There is no Nylo cloud account to delete.

Support

The response-report screen opens an email draft to support only after you choose that action. It shows an exact preview and excludes keys, other messages and attachments; a selected response excerpt is optional. Nothing is delivered unless you send the email in your email app. If you email support, your email and the information you choose to include are received for handling that request. Avoid sending credentials or entire private conversations. Ask support to delete your correspondence when it is no longer needed; retention obligations and the email provider’s processing may apply.

Changes

If later versions add cloud services, accounts or analytics, this policy and the store declarations must be updated before those features are released.
